## Bugs found and fixed

1. **Duplicate evidence frames** (H1) — `flush()` snapshotted, `await`ed the
   write, then popped. Two overlapping flushes wrote the same frames twice;
   9 of 56 files were exactly 2×. Buffer ended correct, so every in-memory
   assertion passed. Fixed with an `asyncio.Lock`.
2. **Dead `FLUSH_INTERVAL_S` override** — bound as a default argument, so
   reassigning the module value did nothing. That kept the background flusher
   racing the final flush.
3. **Silent `end_session()` failure** — `suppress(Exception)` meant a failure
   left the session unended, no job enqueued, evidence orphaned, nothing
   logged, and `ws_disconnected` still fired. Now logs at ERROR.
4. **Garbage-collectable finalizer** — `asyncio.create_task` with no reference
   kept. Now held in `_pending_finalizers`.
5. **`main.py` swallowed the WS router import** — a nested ImportError was
   indistinguishable from "not written yet". Now unconditional.
6. **No CORS** — browser blocked every request while the server returned 200.
   Killed J3's Start button outright. Fixed with `CORSMiddleware`.
7. **Report page ended live sessions** — `POST /session/end` on mount fired
   exactly when a session was still running. Root cause was my own test;
   both fixed.
8. **`session_data/` and test pollution** — ungitignored biometric data, and
   tests writing into the real data directory. Both fixed.
